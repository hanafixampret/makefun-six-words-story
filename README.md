Write a complete story in exactly six words, on anything. A judge model compares entries two at a time against the published brief, and the top three take the $5 pool.

This entry is a single six-word story: a burial on Tuesday, and a dance on Wednesday — a whole marriage, its end, and what came after, left for the reader to fill in. The program validates the text (exactly six words, 1–60 characters) and writes it to `entry.txt`.

## Run it

```sh
node main.ts
```
